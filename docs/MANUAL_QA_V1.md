# Manual QA V1 (Real Android Phone)

- Install APK.
- Add patient (name, relation, optional DOB) and save.
- Restart app and confirm patient persists.
- Add PDF document to patient.
- Restart app and confirm document persists in patient and documents views.
- Open PDF and verify it opens in available PDF viewer.
- Add image document.
- Open image document and verify viewer/preview opens.
- Search by patient name, title, clinic, doctor, and notes/category.
- Add visit for a patient.
- Restart app and confirm visit persists.
- Export backup from Settings to a SAF-selected folder.
- Inspect exported folder contains `MedicalVaultBackup/metadata.json` and `MedicalVaultBackup/files/*`.
